# PyAutoUpdater

[English](./README_EN.md) | [中文](./README.md)

## Overview

PyAutoUpdater is a comprehensive auto-update solution for Python applications, specifically designed for compiled Python tools. It provides standardized auto-update functionality, supporting version detection, incremental updates, and pre/post-update processing, ensuring security and stability for tools in private deployment environments.

## Key Features

- **Multiple Packaging Tool Support**: Compatible with binaries generated by PyInstaller, Nuitka, and other mainstream Python packaging tools
- **Private PyPI Repository Integration**: Support for retrieving updates from private PyPI repositories, including authentication and SSL verification
- **Incremental Updates**: Improve update efficiency by only downloading and applying changes between versions
- **Security Mechanisms**: Support for various signature verification methods (GPG, RSA, simple hash) to ensure update package integrity and authenticity
- **Lifecycle Hooks**: Provide hooks for pre-update, post-update, and error handling, supporting custom business logic
- **Progress Callbacks**: Real-time feedback on update progress and status
- **Backup and Rollback**: Automatically backup files before updating, supporting rollback in case of update failure

```bash
pip install pyautoupdater[security,delta]
```

## Quick Start

### Basic Configuration

Create a configuration file `config.json`:

```json
{
    "package_name": "my-application",
    "current_version": "1.0.0",
    "repositories": [
        {
            "url": "https://private-pypi.example.com",
            "username": "${PYPI_USERNAME}",
            "password": "${PYPI_PASSWORD}",
            "verify_ssl": true
        }
    ],
    "temp_dir": "${TEMP}/my-app-updates",
    "backup_dir": "${TEMP}/my-app-backups",
    "enable_delta": true
}
```

### Basic Usage

```python
from pyautoupdater import UpdateManager
import json

# Load configuration
with open('config.json', 'r', encoding='utf-8') as f:
    config = json.load(f)

# Create update manager
update_manager = UpdateManager(config)

# Check for updates
update_available, latest_version, version_info = update_manager.check_for_updates()
if update_available:
    print(f"New version available: {latest_version}")
    
    # Perform update
    success = update_manager.perform_update(
        progress_callback=lambda progress, message: print(f"Update progress: {progress:.2f} - {message}")
    )
    
    if success:
        print("Update successful, please restart the application")
    else:
        print("Update failed")
else:
    print("Already up to date")
```

## Advanced Usage

### Registering Lifecycle Hooks

```python
from pyautoupdater import UpdateManager, HookManager

# Create hook manager
hook_manager = HookManager()

# Register pre-update hook
def pre_update_hook(version_info):
    print(f"Preparing to update to version {version_info.get('version')}")
    # Perform pre-update preparations, such as closing database connections
    return True  # Return True to continue update, False to abort

hook_manager.register_pre_update_hook(pre_update_hook)

# Register post-update hook
def post_update_hook(version_info):
    print(f"Updated to version {version_info.get('version')}")
    # Perform post-update tasks, such as migrating configuration files
    return True

hook_manager.register_post_update_hook(post_update_hook)

# Create update manager with hook manager
update_manager = UpdateManager(config, hook_manager=hook_manager)
```

### Enabling Security Verification

```python
from pyautoupdater import UpdateManager, SecurityManager

# Security configuration
security_config = {
    "signature_verification": True,
    "signature_type": "rsa",
    "public_key_path": "path/to/public_key.pem"
}

# Create security manager
security_manager = SecurityManager(security_config)

# Create update manager with security manager
update_manager = UpdateManager(config, security_manager=security_manager)
```

### Enabling Delta Updates

```python
from pyautoupdater import UpdateManager, DeltaManager

# Delta update configuration
delta_config = {
    "enable_delta": True,
    "manifest_filename": "manifest.json",
    "chunk_size": 4096
}

# Create delta manager
delta_manager = DeltaManager(delta_config)

# Create update manager with delta manager
update_manager = UpdateManager(config, delta_manager=delta_manager)
```

## API Reference

### UpdateManager

The update manager responsible for handling the update process.

```python
UpdateManager(config, hook_manager=None, security_manager=None, delta_manager=None)
```

Main methods:
- `check_for_updates()`: Check for available updates
- `perform_update()`: Perform the update process
- `rollback_update()`: Roll back to the previous version

### HookManager

The manager for update lifecycle hooks.

```python
HookManager()
```

Main methods:
- `register_pre_update_hook(hook)`: Register a pre-update hook
- `register_post_update_hook(hook)`: Register a post-update hook
- `register_error_hook(hook)`: Register an error handling hook

### SecurityManager

The manager for update security.

```python
SecurityManager(config=None)
```

Main methods:
- `verify_signature(file_path, version_info)`: Verify file signature
- `verify_hash(file_path, expected_hash)`: Verify file hash

### DeltaManager

The manager for delta updates.

```python
DeltaManager(config=None)
```

Main methods:
- `generate_manifest(directory)`: Generate a file manifest
- `compare_manifests(old_manifest, new_manifest)`: Compare manifests to find differences
- `apply_delta_update(app_dir, delta_dir, changes)`: Apply a delta update

### PackageAdapter

Base class for package adapters for different packaging tools.

```python
PackageAdapter.detect_package_type(app_dir)
PackageAdapter.create_adapter(package_type)
```

Derived classes:
- `PyInstallerAdapter`: Adapter for PyInstaller packages
- `NuitkaAdapter`: Adapter for Nuitka packages
- `HybridAdapter`: Adapter for hybrid packages
- `StandardAdapter`: Adapter for standard Python packages
