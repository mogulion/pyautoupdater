# PyAutoUpdater 与 PyDistMaker 集成使用说明

## 概述

PyAutoUpdater 是一个全面的 Python 应用程序自动更新解决方案，专为编译型 Python 工具设计。本文档详细说明如何在使用 PyDistMaker 打包的项目中集成 PyAutoUpdater 自动更新功能。

## 集成步骤

### 1. 安装依赖

首先，确保安装了必要的依赖包：

```bash
pip install pyautoupdater pydistmaker
```

### 2. 项目结构

一个典型的集成了 PyAutoUpdater 的 PyDistMaker 项目结构如下：

```
./
├── app.py                # 主应用程序
├── config.json           # PyAutoUpdater 配置文件
├── pydistmaker.json      # PyDistMaker 配置文件
├── keys/                 # 密钥目录
│   ├── public_key.pem    # 用于验证更新包签名的公钥
│   └── private_key.pem   # 用于签名更新包的私钥（不应包含在发布版本中）
└── README.md             # 项目说明文档
```

### 3. 配置 PyAutoUpdater

在 `config.json` 文件中配置 PyAutoUpdater：

```json
{
    "package_name": "my-application",
    "current_version": "1.0.0",
    "repositories": [
        {
            "url": "https://private-pypi.example.com",
            "username": "${PYPI_USERNAME}",
            "password": "${PYPI_PASSWORD}",
            "verify_ssl": true
        }
    ],
    "temp_dir": "${TEMP}/my-app-updates",
    "backup_dir": "${TEMP}/my-app-backups",
    "max_download_retries": 3,
    "chunk_size": 8192,
    "timeout": 30,
    "proxy": null,
    "enable_delta": true,
    "security": {
        "signature_verification": true,
        "signature_type": "rsa",
        "public_key_path": "${APP_DIR}/keys/public_key.pem",
        "trusted_fingerprints": []
    },
    "delta": {
        "enable_delta": true,
        "manifest_filename": "manifest.json",
        "chunk_size": 4096
    }
}
```

配置说明：

- `package_name`: 应用程序包名，用于在更新源中查找更新
- `current_version`: 当前版本号，遵循语义化版本规范
- `repositories`: 更新源仓库列表，支持多个备用源
- `temp_dir`: 临时目录，用于下载和解压更新包
- `backup_dir`: 备份目录，用于在更新失败时回滚
- `security`: 安全配置，包括签名验证方式和公钥路径
- `delta`: 增量更新配置，可减少更新包大小

### 4. 配置 PyDistMaker

在 `pydistmaker.json` 文件中配置 PyDistMaker：

```json
{
    "app_name": "my-application",
    "version": "1.0.0",
    "entry_point": "app.py",
    "output_dir": "dist",
    "icon": null,
    "console": true,
    "onefile": true,
    "include_files": [
        "config.json",
        "keys/public_key.pem"
    ],
    "hidden_imports": [
        "pyautoupdater"
    ],
    "exclude_modules": [],
    "runtime_hooks": [],
    "additional_args": [
        "--clean"
    ]
}
```

配置说明：

- `app_name`: 应用程序名称，应与 PyAutoUpdater 配置中的 `package_name` 保持一致
- `version`: 应用程序版本，应与 PyAutoUpdater 配置中的 `current_version` 保持一致
- `include_files`: 需要包含在打包结果中的文件列表，**必须包含** `config.json` 和公钥文件
- `hidden_imports`: 隐式导入的模块，**必须包含** `pyautoupdater`

### 5. 在应用程序中集成 PyAutoUpdater

在主应用程序中集成 PyAutoUpdater 的核心步骤：

1. 导入必要的模块
2. 获取应用程序目录（打包环境与开发环境不同）
3. 加载配置文件并处理环境变量
4. 创建更新管理器
5. 检查更新并执行更新

示例代码片段：

```python
# 导入 PyAutoUpdater
from pyautoupdater import UpdateManager, HookManager, SecurityManager, DeltaManager

# 获取应用程序目录
def get_app_dir():
    if getattr(sys, 'frozen', False):
        # 打包环境
        if hasattr(sys, '_MEIPASS'):  # PyInstaller
            app_dir = sys._MEIPASS
        else:  # 其他打包工具，如 PyDistMaker
            app_dir = os.path.dirname(sys.executable)
    else:
        # 开发环境
        app_dir = os.path.dirname(os.path.abspath(__file__))
    return app_dir

# 加载配置
app_dir = get_app_dir()
config_path = os.path.join(app_dir, 'config.json')
with open(config_path, 'r', encoding='utf-8') as f:
    config = json.load(f)

# 处理环境变量
# ...

# 创建更新管理器
update_manager = UpdateManager(config)

# 检查更新
update_available, latest_version, version_info = update_manager.check_for_updates()
if update_available:
    # 执行更新
    success = update_manager.perform_update(
        progress_callback=lambda progress, message: print(f"更新进度: {progress:.2f} - {message}")
    )
```

## 注意事项

### 1. 路径处理

在打包环境中，应用程序目录的获取方式与开发环境不同：

- 在开发环境中，可以使用 `os.path.dirname(__file__)` 获取当前脚本所在目录
- 在打包环境中，需要使用 `sys.executable` 或 `sys._MEIPASS`（PyInstaller 特有）获取应用程序目录

示例：

```python
def get_app_dir():
    if getattr(sys, 'frozen', False):
        # 打包环境
        app_dir = os.path.dirname(sys.executable)
    else:
        # 开发环境
        app_dir = os.path.dirname(os.path.abspath(__file__))
    return app_dir
```

### 2. 环境变量处理

PyAutoUpdater 配置文件中支持使用环境变量，格式为 `${ENV_VAR}`。在加载配置时，需要处理这些环境变量：

```python
def load_config(config_path):
    with open(config_path, 'r', encoding='utf-8') as f:
        config = json.load(f)
    
    # 处理环境变量
    for key, value in config.items():
        if isinstance(value, str) and value.startswith('${') and value.endswith('}'):
            env_var = value[2:-1]
            if env_var == 'APP_DIR':
                config[key] = get_app_dir()
            else:
                config[key] = os.environ.get(env_var, value)
    
    # 处理嵌套字典中的环境变量
    # ...
    
    return config
```

### 3. 安全性考虑

- **公钥与私钥**: 公钥用于验证更新包签名，应包含在发布版本中；私钥用于签名更新包，**不应**包含在发布版本中
- **签名验证**: 建议启用签名验证，防止恶意更新
- **HTTPS**: 建议使用 HTTPS 协议的更新源，防止中间人攻击

### 4. 更新流程设计

- **更新前备份**: 在执行更新前，应备份当前版本，以便在更新失败时回滚
- **增量更新**: 启用增量更新可减少更新包大小，提高更新效率
- **更新钩子**: 使用更新钩子可在更新前后执行自定义操作，如配置迁移、服务重启等

### 5. 打包注意事项

- **版本一致性**: 确保 PyDistMaker 配置中的版本号与 PyAutoUpdater 配置中的版本号一致
- **文件包含**: 确保将 `config.json` 和公钥文件包含在打包结果中
- **隐式导入**: 确保将 `pyautoupdater` 添加到隐式导入列表中

## 最佳实践

### 1. 版本管理

- 使用语义化版本规范（SemVer）管理版本号
- 在每次发布新版本时，同步更新 PyDistMaker 配置和 PyAutoUpdater 配置中的版本号

### 2. 更新源管理

- 配置多个备用更新源，提高更新可靠性
- 使用私有 PyPI 仓库或对象存储服务作为更新源
- 为更新源配置适当的访问控制

### 3. 用户体验优化

- 提供更新进度反馈，让用户了解更新状态
- 在更新失败时提供详细的错误信息和解决方案
- 允许用户选择是否立即更新或稍后更新

### 4. 测试与验证

- 在发布更新前，在各种环境中测试更新流程
- 验证更新包的完整性和签名
- 测试更新失败时的回滚机制

## 常见问题

### 1. 更新失败如何处理？

更新失败可能有多种原因，如网络问题、签名验证失败、文件权限问题等。建议：

- 记录详细的错误日志
- 实现自动回滚机制
- 提供手动更新选项

### 2. 如何处理配置文件迁移？

在版本更新时，配置文件格式可能发生变化。可以使用更新钩子在更新前执行配置迁移：

```python
def config_migration_hook(version_info):
    # 根据版本信息执行不同的迁移逻辑
    if version_info.get('version') == '1.1.0':
        # 执行 1.0.0 到 1.1.0 的配置迁移
        pass
    return True

# 注册钩子
hook_manager = HookManager()
hook_manager.register_pre_update_hook(config_migration_hook)
```

### 3. 如何在更新后重启应用程序？

在更新完成后，通常需要重启应用程序以应用新版本。可以使用更新钩子在更新后执行重启：

```python
def restart_application():
    if getattr(sys, 'frozen', False):
        # 打包环境
        os.execl(sys.executable, sys.executable, *sys.argv)
    else:
        # 开发环境
        os.execl(sys.executable, sys.executable, *sys.argv)

# 注册钩子
hook_manager = HookManager()
hook_manager.register_post_update_hook(lambda _: restart_application())
```
